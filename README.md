Machine Learning Engineer and Data Scientist based in Nicosia, Cyprus, with a Ph.D. in Computer Engineering (University of Cyprus) and 7+ years of applied research. Specialises in **physics-informed neural networks (PINNs)** and **adversarially robust machine learning** for safety-critical cyber-physical systems and smart grids, across the full ML lifecycle: data pipelines, feature engineering, model training, hyperparameter optimisation, and reproducible evaluation.
